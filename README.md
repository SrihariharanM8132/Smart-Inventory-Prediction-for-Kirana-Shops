# 🏪 Smart Inventory Prediction for Kirana Shops

**AI-Powered Demand Forecasting System for Local Retail Stores**

Built for OpenAI Academy × NxtWave Buildathon 2025

---

## 🎯 Problem Statement

Indian Kirana shops lose revenue daily due to:
- **Overstocking**: Capital locked in excess inventory, leading to wastage
- **Understocking**: Lost sales opportunities and unhappy customers
- **Manual Tracking**: Time-consuming, error-prone stock management
- **Festival Demand**: Inability to predict seasonal spikes

## 💡 Solution

Smart Inventory Prediction uses AI and machine learning to:
- Analyze historical sales patterns automatically
- Detect trends (increasing, decreasing, stable, volatile)
- Forecast demand for 7-90 days ahead
- Adjust predictions for festival seasons
- Provide actionable stock recommendations

## ✨ Key Features

### 🔮 Dynamic Forecasting
- **Trend Detection**: Automatic identification of sales patterns
- **Confidence Intervals**: Uncertainty ranges for better planning
- **Festival Boost**: Seasonal demand adjustments (Diwali, Pongal, etc.)

### 📊 Interactive Dashboard
- Real-time visualization of historical sales and predictions
- Product-wise analytics and insights
- Downloadable CSV reports

### 💡 AI-Powered Insights
- Smart stock recommendations
- Volatility alerts for high-risk products
- Personalized reorder suggestions

## 🚀 Tech Stack

- **Frontend**: Streamlit (Interactive Web UI)
- **Backend**: Python 3.8+
- **ML/Forecasting**: 
  - Holt-Winters Exponential Smoothing
  - Custom trend detection algorithms
  - Statistical analysis (statsmodels, scipy)
- **Visualization**: Plotly (Interactive charts)
- **Data Processing**: Pandas, NumPy
